# Sales Director Lead Gen — Releases

Public distribution repo for **Sales Director Lead Gen** (macOS, Apple Silicon + Intel).
Releases carry the notarized DMGs plus the signed `.app.tar.gz` packages used by the
app's built-in updater; `updates/latest.json` on `main` is the update manifest endpoint.

Source code lives in the private `christopherstaats/lead-harvester` repo.
